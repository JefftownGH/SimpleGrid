# 本地变更记录

## 2026-09-10

### 公开项目命名

- 公开品牌和最终仓库名确定为 `SimpleGrid`，中文名为“简单格子”。
- 可执行文件、进程、程序集、命名空间、项目文件、安装目录和数据目录统一改名为 `SimpleGrid`。
- 旧 `%LOCALAPPDATA%\NoFences` 数据通过复制及 XML 路径改写迁移，旧目录保留作回滚。
- 新增首次启动自动迁移和 `fences.index`，避免受限登录任务依赖 GUID 子目录枚举。
- 启动时按实际成功加载数量判断是否创建默认围栏，防止误建空白 “First fence”。
- README 补充品牌定位、兼容边界及与上游项目的关系。

### 自有项目仓库

- 新增 `%LOCALAPPDATA%\SimpleGrid\Items` 中央仓库。
- 外部文件、快捷方式或目录拖入时，先创建自有副本，再写入围栏元数据。
- 每个项目使用随机容器目录，避免同名冲突。
- 已在仓库中的项目直接复用；导入失败时不污染围栏列表，并清理未完成目录。
- 围栏内部和跨围栏移动继续只修改元数据，不重复复制项目。

### 快速右键菜单

- 普通右键改为 SimpleGrid 快速菜单，避免同步加载全部 Shell 扩展。
- 菜单打开前锁定实际命中项目，避免鼠标离开窗口后删除目标丢失。
- 删除时清理同一路径的大小写变体和重复记录。
- 新增“在资源管理器中打开”，打开目录并选中对应项目。
- `Shift + 右键` 保留完整 Windows Shell 菜单。

### 高 DPI 拖错图标修复与可靠性检查

- 修正绘制换行与命中测试使用不同列数公式的问题，覆盖 100%—200% DPI 缩放。
- 点击、拖动和插入线改用同一份可见项目布局，并正确映射列表中的失效路径。
- 释放绘制、字体、缩略图和高清图标替换过程中的 GDI 资源。
- 缩略图改为线程安全的共享限流缓存和流式读取，窗口关闭时释放缓存。
- 窗口移动/缩放保存改为 UI 定时器节流，缩放重绘不再同步阻塞。
- 围栏 XML 改为临时文件原子替换；单个损坏围栏不再阻止其他围栏启动。
- 加载后及时释放 XML 读句柄，并抑制窗口构造阶段的位置/尺寸保存，防止启动时争用或覆盖布局。
- 普通项目启动改用线程池任务，避免每次启动新增长生命周期线程。

### 图标拖拽排序

- 增加围栏内图标拖拽排序。
- 增加跨围栏移动。
- 增加目标格子插入位置提示。
- 外部文件拖放改为按鼠标位置插入。
- 内部移动后立即保存两个围栏的顺序，不移动项目对应的真实文件。
- 锁定围栏继续禁止内容拖放。
- 增加同围栏、跨围栏及去重移动的程序化验证。

## 2026-09-09

### Explorer 卡顿修复

- `.lnk` 快捷方式解析后直接启动目标 EXE，降低对 Explorer Shell 启动路径的依赖。
- 将 Shell 高清图标解析移出 UI 线程，并限制后台并发数。
- 图标未加载时使用即时占位图，完成后安全通知窗口刷新。
- 鼠标移动刷新限频为约 32 ms。
- 双击启动脱离绘制函数，避免启动和重绘互相耦合。
- 修复缩略图 HICON 克隆与释放。

### 构建恢复

- 从本机定制版恢复可编译源码。
- 保留中文资源、高 DPI、Windows 11 桌面集成和诊断日志。
- 为反编译资源格式加入 `System.Resources.Extensions` 构建依赖。
